## What Is Machine Learning?

Machine learning is an artificial intelligence approach where computers are capable of learning without being explicitly programmed. Machine learning makes it possible for computers to learn patterns from data instead of being programmed by a programmer on how to react to every situation.

Machine learning algorithms have a lot of applications ranging from recommendation systems, spam email filters, virtual assistants like Alexa, and image and video recognition.

## Types of Machine Learning

There are three main types of machine learning:

1. Supervised learning: The algorithm uses labelled examples. Examples are e-mails labelled as spam and not spam.

2. Unsupervised learning: Patterns are extracted from unlabeled data by the algorithm.

3. Reinforcement Learning: It involves decision-making in the environment according to the feedback provided to the agent or user in the form of rewards.

Machine learning is closely related to [[neural-networks|Neural Networks]], which are used in many modern AI applications. Additionally, machine learning is an important part of [[generative-ai|Generative AI]], which creates content based on learned patterns.

### Why Does It Matter

Knowledge about machine learning helps to better comprehend how modern AI applications generate their predictions using the data received. Besides, it shows the significance of training data for AI.
